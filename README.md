# 🌸 Aura Health AI

## 🚀 Problem
Many women face irregular menstrual cycles and PCOD risk but lack accessible, intelligent tools for tracking and understanding their health.

## 💡 Solution
Aura Health AI is an AI-powered mobile app that:
- Predicts menstrual cycles
- Detects PCOD risk using pattern analysis
- Provides emotional and health support via AI chatbot

## ✨ Features
- 📊 Cycle Prediction (range-based)
- ⚠️ PCOD Risk Detection (Low / Medium / High)
- ➕ Cycle Data Tracking
- 🤖 AI Chatbot (empathetic health support)
- 📱 Clean, user-friendly UI

## 🧠 Tech Stack
- React Native (Expo)
- JavaScript
- (MVP uses frontend-based logic)

## 🎯 Future Scope
